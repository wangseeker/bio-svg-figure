# 教材作图批量方法（F7 定稿复盘 · 2026-09-02）

> 目标：一次定稿一套方法，批量产出第十二章 F1–F18 全部配图，风格/大小/字体/颜色统一、可编辑、满足出版。

---

## 一、定稿技术栈（走通的最优路线）
**程序化 SVG（Nature Reviews 矢量风）** —— 不是 AI 生图、不是 BioGDP 手拖。
- 零漂移（坐标代码定）、可编辑矢量（SVG→Illustrator/AI 打开改）、满足出版矢量要求、可批量。
- 风格 = NR 扁平矢量：圆角矩形节点、统一箭头、柔和协调配色、无衬线标签、**线条膜**（简洁，不用磷脂头尾）、β-氧化用**四箭头循环**表示分步。

## 二、固定规范（模板常量，全章统一）
| 项 | 固定值 |
|----|--------|
| 图幅 | 通栏 **150×100mm**（3:2），= 150mm 版心宽 |
| 分辨率 | ≥300dpi（SVG 矢量无损；导出 1772×1181 PNG）|
| 字号 | 主标签 **9pt** / 副标 **7.5pt** / 最小 **6pt**；全图统一 |
| 字体 | 中文黑体；英文/数字 Helvetica/Arial |
| 颜色 | 蓝#4A7DBF 橙#E8A87C 紫#9B7FC0 绿#8FBF8F 粉#D98A8A 灰#5A5A5A 抑制#C0392B；背景/分区淡色 |
| 图注 | 放 Word（图下方宋体小五），不在图内 |

## 三、元件函数库（SVG 可复用，定义一次全章用）
- `ball(cx,cy,r,fill,stroke)` 分子球（带高光）
- `node(x,y,w,h,label,fill,edge)` 圆角矩形酶/节点（NR 模块）
- `arrow(x0,y0,x1,y1,color,dash)` 统一箭头（可虚线=T 头抑制）
- `beta_cycle(cx,cy,r,labels)` β-氧化**四箭头循环环**（四步各一箭头+方位标签）
- `membrane(cx,cy,rx,ry)` 简洁**线条双层膜**（外膜+内膜+嵴曲线）
- `region(x,y,w,h,title)` 分区底块（胞质/线粒体）+ 标题
- 顶部信息带、脂滴球、长链分子等

## 四、批量流程（每张图步骤）
1. **定主题/要素**：该图画什么（酶/分子/通路/细胞器）、分几区、标签文字（术语对齐课本）
2. **写配置**：各元件坐标 + 标签 + 配色（用上面常量，不另起颜色）
3. **拼装脚本**：调元件函数 → 生成 `图名.svg`
4. **导出**：SVG 矢量（AI 打开可编辑）+ 300dpi PNG（Word 用）
5. **验收**：**以用户肉眼 + AI/Illustrator 打开看**为准（勿依赖机评 VL 判断视觉）
6. **图注**：写入 Word（图下方）

## 五、坑与对策（走过的弯路）
| 坑 | 对策 |
|----|------|
| ❌ AI 生图（qwen-image）作图 | 文字必错字、构图漂移、位图不满足投稿矢量、无法精确结构 → **弃用**，只可用作灵感参考 |
| ❌ image-to-image 改一处必漂移 | 结构定位同 seed/改 prompt 不解决 → 改走程序化 |
| ❌ 机械评审（VL 小图）判视觉 | 看不清就判否 → **以人眼 + 矢量放大看为准** |
| ❌ BioGDP/BioRender 手拖 | 太慢、依赖登录、不可批 → 弃用（仅单张精美可考虑）|
| ❌ 磷脂双分子层繁琐 | 用户弃用 → 膜用**简洁线条** |
| ❌ 颜色混乱 | **统一色板**，每个元件固定色号 |
| ❌ β-氧化单环不清 | 改**四箭头循环**（四步各一箭头）|
| ❌ 未先定版式就作图 | **先定尺寸/字号/色板**，避免返工 |
